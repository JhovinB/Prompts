# Prompts Repository

Este repositorio es mi biblioteca personal de **prompts optimizados** para diferentes modelos de Inteligencia Artificial (como ChatGPT, Claude, Midjourney, entre otros). Aquí organizo y almaceno las instrucciones que mejor resultado me han dado para automatizar tareas, programar, escribir y diseñar.

---
## Cómo Utilizar los Prompts

Para obtener los mejores resultados al copiar estos prompts, te sugiero seguir estas recomendaciones:

1. **Reemplaza los corchetes:** Muchos prompts tienen variables entre corchetes como `[tu tema]` o `[idioma]`. Asegúrate de cambiarlos por tus datos antes de enviar el mensaje.
2. **Asigna un rol:** Si el prompt no lo incluye, inicia la conversación definiendo la profesión de la IA (ej. *"Actúa como un experto en SEO..."*).
3. **Itera el resultado:** Usa el prompt como base y añade contexto adicional si la primera respuesta no es exactamente lo que buscas.
